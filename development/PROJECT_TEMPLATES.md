# Project-side Templates — Copy Before UI Implementation

These are **two concise records** generated by the Code Agent for each requested web project. They are not user-facing page content and are not a request to write a large design report. Copy the relevant sections into the actual project under `docs/` before implementation. Replace brackets with the task's real requirements; do not fabricate known decisions.

## How to use

1. The Code Agent fills **the plan and the expected-evidence columns** first, not score columns.
2. Freeze them. Then implement the site.
3. Fill **Initial** ratings after opening actual screenshots and running tests.
4. Revise only when needed, preserve useful design, capture matching after screens.
5. Fill **Final** ratings and critical gates with evidence. Apply deterministic arithmetic per [SCORECARD](../validation/SCORECARD.md).
6. If a required field or test is unknown, write **UNVERIFIED**. No guessed values and no automatic final PASS.

A user needs to provide only the original development brief; the agent handles these records internally.
